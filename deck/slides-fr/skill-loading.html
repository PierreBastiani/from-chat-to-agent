5 · Les skills

Pour démystifier : une skill, c’est ce que vous feriez à la main en disant « lis ce fichier et suis-le ». Aucun mécanisme nouveau : la skill utilise l’outil « lire » de la version 3. Le harnais ajoute seulement le sommaire au prompt système. C’est pour ça qu’on peut avoir beaucoup de skills sans remplir la fenêtre de contexte. Dans la vraie session de la démo 1, on voit Claude Code charger la skill « dataviz » de lui-même.
