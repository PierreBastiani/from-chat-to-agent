# fait un titre, ** du gras, - une liste. Peu de signes, donc peu de tokens : c’est le format des fichiers de règles et des skills.

4 · La boucle

Markdown existait bien avant les LLM : c’est une façon d’écrire de la doc en texte brut. Il se lit aussi bien brut que rendu (dans un navigateur, sur GitHub, dans VS Code). Les agents l’utilisent partout parce qu’il coûte peu de tokens, contrairement à du HTML plein de balises. Pour lire un fichier .md dans le terminal : cat regles.md ; pour le voir rendu : l’ouvrir dans VS Code et choisir l’aperçu.
