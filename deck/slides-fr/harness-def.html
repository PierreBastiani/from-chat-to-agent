Le harnais, c’est le programme autour du modèle

Vous

Vous tapez une question.

Le harnais

Il met en forme le texte, appelle le modèle, coupe la réponse et l’affiche.

Le modèle

Il complète le texte qu’on lui donne.

Le modèle ne voit que du texte. La mise en forme, l’arrêt et l’affichage sont faits par le harnais.

2 · Le chat

ChatGPT, l’application Gemini, Antigravity et Claude Code sont des harnais. Avec le même modèle derrière, deux harnais donnent deux outils très différents. Le mot vient de l’anglais « harness ».
