# Rapport de lot

1. Trouver et vérifier les fichiers. Si les noms ne collent pas, demander.

2. Lancer : python3 scripts/rapport.py <lot> <limites> rapport.html

3. L'analyse 3 sigma est toujours incluse.

4. Répondre : FAIL et rendement d'abord, puis ce qui mérite un regard.

Une skill est un dossier : ce fichier, parfois des scripts. Celle-ci, l’agent l’écrira lui-même pendant la démo 2.

5 · Les skills

Ce ne sont pas des binaires : une skill est du Markdown, avec éventuellement des scripts Python ou Bash à côté. Une recette, écrite comme on l’écrirait pour un collègue. N’importe qui dans l’équipe peut en lire une, la corriger, en écrire une, la partager. Les lignes en bleu, le nom et la description, sont les seules que le harnais lit au démarrage. Le fichier montré ici est un extrait de la skill écrite par l’agent pendant la séance du 22 novembre.
