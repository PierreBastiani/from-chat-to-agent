5 · Les skills

Claude Code demande l’autorisation d’écrire dans ~/.claude/skills : c’est un dossier protégé, dire oui. Dans la session enregistrée : 2 minutes. L’agent a sorti le script du dossier temporaire, l’a nettoyé pour qu’il serve à d’autres lots (limites lues par position, colonnes vides signalées), l’a lancé sur le lot B pour vérifier, puis a écrit le SKILL.md. Afficher le SKILL.md et le lire : c’est une doc, on peut la corriger à la main.
