Si on devait le coder · les permissions

Pseudo-code du harnaisversion 4 / 7

messages = [système, user(tâche)]

répéter :

    réponse = modèle(messages, outils = [bash, lire, écrire, chercher])

    messages += réponse

    si réponse n'appelle aucun outil : afficher(réponse.texte) ; arrêter

    pour chaque appel dans réponse.appels :

        # permission : c'est le harnais qui demande, pas le modèle

        si appel.nom == "bash" et non demander("Autoriser ?") :

            résultat = "refusé par l'utilisateur"

            # le modèle lit « refusé » et cherche une autre voie

        sinon :

            résultat = exécuter(appel)

        messages += résultat_outil(appel, résultat)

Trois lignes ajoutées, en orange. La question « Autoriser ? » est posée par le programme, avant d’exécuter : le modèle n’a aucun moyen de la sauter. Dans la vraie session de la démo 1, Claude Code a refusé deux commandes ; l’agent a lu le refus et a relancé autrement.
