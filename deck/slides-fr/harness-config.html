Ce qu’on règle dans un harnais agentique

Modèle et mode

Quel modèle pour quelle tâche, et jusqu’où l’agent agit seul : commandes du terminal, relecture des changements.

Règles

Le fichier de règles lu au début de chaque conversation, global ou par projet : CLAUDE.md, GEMINI.md, AGENTS.md.

Accès

Les serveurs MCP vers vos bases et vos services, déclarés dans un fichier de configuration. En entreprise, l’admin fixe la liste autorisée.

Skills

Les dossiers que le harnais parcourt au démarrage, et les skills qu’il liste pour le modèle.

Pour savoir ce qu’il a vraiment lu, demandez-lui : « Qu’est-ce que tu as dans ton contexte ? »

7 · Votre harnais

Chaque harnais agentique a ces quatre réglages, sous d’autres noms : Claude Code, Antigravity, Codex CLI, Cursor. Sur le choix du modèle : un modèle rapide pour les petites tâches répétitives, le plus gros pour les tâches longues qui demandent du raisonnement. Le mode décide combien de fois le harnais demande avant d’agir.
