Règles de permission

Réglages du harnais

Le harnais décide ce qu’il exécute. Le modèle ne peut pas contourner ces règles, puisque c’est le harnais qui lance la commande.

En entreprise, l’IT peut fixer ces règles pour tout le monde, par exemple la liste des serveurs MCP autorisés.

4 · La boucle

Écrire « ne supprime jamais de fichier » dans le fichier de règles réduit le risque, sans l’exclure. Interdire rm dans les permissions l’exclut. Dans Claude Code, la doc le dit explicitement : les instructions influencent ce que Claude essaie, les permissions décident ce qui est autorisé. Dans Antigravity, les administrateurs peuvent imposer la liste des serveurs MCP approuvés.
