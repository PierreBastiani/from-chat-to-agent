tools = [bash, read, write, search]

for each server in mcp_config:

    tools += server.list_tools()  # one name and one description per tool

messages = [system, user(task)]

repeat:

    reply = model(messages, tools)

    messages += reply

    if reply calls no tool: show(reply.text); stop

    for each call in reply.calls:

        if call.server:

            result = call.server.run(call)  # the server checks access rights

        else: result = run(call)  # permissions from version 4

        messages += tool_result(call, result)

4 · The loop

MCP stands for Model Context Protocol. An MCP server is an API, an entry point to a service (a spec database, a simulation launcher, Confluence), in a format that harnesses know how to read: a name and a description for each tool. The harness adds these tools to its list, and the model calls them exactly like bash or read. The difference is on the other side: the server runs the call, checks who is asking and what is allowed, and keeps the log of calls. That is safer than letting the agent log in over SSH with the user’s rights. The protocol is public and every harness implements it: a service writes its server once, and anyone can plug it in.
