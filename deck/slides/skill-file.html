# Lot report

1. Find and check the files. If the names don't match, ask.

2. Run: python3 scripts/rapport.py <lot> <limits> report.html

3. The 3 sigma analysis is always included.

4. Reply with FAIL count and yield first, then what deserves a look.

A skill is a folder: this file, sometimes scripts. The agent will write this one itself during demo 2.

5 · Skills

No binaries here. A skill is Markdown, sometimes with Python or Bash scripts next to it. It is a recipe, written the way you would write it for a colleague. Anyone on the team can read one, fix it, write one, share it. The blue lines, the name and the description, are the only ones the harness reads at startup.
