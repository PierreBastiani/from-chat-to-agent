5 · Skills

To take the mystery out: a skill is what you would do by hand when you say “read this file and follow it”. There is no new mechanism; the skill uses the “read” tool from version 3. The harness only adds the table of contents to the system prompt. That is why you can have many skills without filling the context window. In the real session of demo 1, you can see Claude Code load the “dataviz” skill on its own.
