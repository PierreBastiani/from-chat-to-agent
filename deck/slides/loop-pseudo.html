messages = [system, user(task)]

# a list: system, user, model, tool, model… joined end to end,

# it is the same text as before, split by role

repeat:

    reply = model(messages, tools = [bash, read, write, search])

    messages += reply

    if reply calls no tool: show(reply.text); stop

    for each call in reply.calls:

        result = run(call)

        messages += tool_result(call, result)

We rewrite the chat as a loop, and “text” becomes a list of messages. In orange, what did not exist in version 2.

4 · The loop

The chat loop is still there. “text” becomes “messages”: the same thing, split by role. Each message carries a label (system, user, model, tool result). Before calling the model, the harness joins them end to end with the tags we saw on the chat slide. The model still reads a single text. What changes: the model gets a list of tools, and control goes back to the user only when it stops calling them. A real task goes through this loop dozens of times.
