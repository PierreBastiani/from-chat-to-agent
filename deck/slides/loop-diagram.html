The agentic loop

1

Think

The model reads all the text again and picks a tool.

2

Act

The harness runs the call: command, read, write.

3

Observe

The result is added to the text.

↺ repeat as long as the model calls a tool

No tool call → final reply, end of the loop

A real task often takes dozens of turns.

4 · The loop

An agent is a model in this loop, with tools. The stop condition is at the top: when the model replies without calling a tool, the harness hands control back. Concrete example: "run the simulation and fix the error". Turn 1, it runs make sim. Turn 2, it reads the log. Turn 3, it opens the faulty file. Turn 4, it edits it. Turn 5, it runs it again. Turn 6, no more errors, it replies without a tool and the loop stops.
