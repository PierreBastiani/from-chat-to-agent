What you set in an agentic harness

Model and mode

Which model for which task, and how far the agent acts on its own: terminal commands, reviewing changes.

Rules

The rules file read at the start of every conversation, global or per project: CLAUDE.md, GEMINI.md, AGENTS.md.

Access

The MCP servers to your databases and services, declared in a config file. In a company, the admin sets the allowed list.

Skills

The folders the harness scans at startup, and the skills it lists for the model.

To find out what it actually read, ask it: “What’s in your context?”

7 · Your harness

Every agentic harness has these four settings, under different names: Claude Code, Antigravity, Codex CLI, Cursor. On choosing the model: a fast model for small repetitive tasks, the largest one for long tasks that need reasoning. The mode decides how often the harness asks before acting.
