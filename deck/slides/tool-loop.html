Harness pseudo-codeversion 2 / 7

text = ""

repeat:

    question = read_keyboard()

    text += "user: " + question + "\nmodel: "

    reply = model.complete(text, stop = ["user:", "</search>"])

    if reply ends with "</search>":

        results = web_search(between_tags(reply))

        text += reply + "<result>" + results + "</result>"

        reply = model.complete(text, stop = "user:")

    show(reply)

    text += reply + "\n"

The added lines are in orange. The model writes the query, the harness runs the search.
