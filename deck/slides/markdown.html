4 · The loop

Markdown existed long before LLMs. It is a way to write documentation in plain text, and it reads just as well raw as rendered (in a browser, on GitHub, in VS Code). Agents use it everywhere because it costs few tokens, unlike HTML full of tags. To read a .md file in the terminal: cat rules.md. To see it rendered, open it in VS Code and choose the preview.
