2 · The chat

Each model family has its own tokens. These come from the ChatGPT line and Qwen uses them too; Qwen is the local model in the demo. Gemini’s format is not public, but the principle is the same. What the user sees as chat bubbles, the model sees as one long text with tags. The system prompt, when there is one, is plain text placed at the start.
